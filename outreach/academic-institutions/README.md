# Academic Institution Outreach Package

This folder contains the institution-facing brochures and pitch material.

## Structure

- `brochures/latex/` contains editable LaTeX sources and the shared visual style.
- `brochures/pdf/` contains generated brochure PDFs created by GitHub Actions.
- `pitch/` contains the one-slide executive pitch source and generated PDF/PNG assets.

## Recommended use

Start with the one-slide pitch. Share the Academic Innovation Partnership brochure when an institution wants more detail, then share the most relevant program brochure for the selected cohort.

The material emphasizes visible participant outputs, a focused pilot, evidence, review points and a clear continuation path. Generated brochures are also copied to `downloads/` so existing website links remain compatible.
