# Generated academic outreach assets

This folder is the repository-native archive for the visual assets developed during the academic outreach work.

## Structure

- `flyers/` — scalable SVG flyers for each academic program.
- `pitch-slides/` — scalable 16:9 SVG renditions of the AI-era academic innovation pitch story.
- `pitch/` — the executive one-slide institutional pitch rendition.

The SVG files are intentionally repository-native and scalable so that the website can display them without pixelation and academic teams can download them directly. They preserve the narrative, hierarchy and visual language of the generated chat assets while remaining easy to version and maintain in Git.
