Why some city or referrer rows may be empty: the public summary deliberately suppresses city groups with fewer than 3 anonymous visitors and referrer groups with fewer than 3 sessions. If a live check fails

  1. Open Cloudflare → Workers & Pages → amarbanerjee23-github-io → Builds.
  2. Confirm the latest production build from GitHub main completed successfully.
  3. Refresh this diagnostics page after the Worker deployment finishes.
  4. If the configuration is connected but the live checks show TypeError: Failed to fetch, the browser could not read the Worker response. The Worker health and summary endpoints are expected to allow this GitHub Pages origin through CORS.

Visitor analytics is written directly to D1. This diagnostics page is read-only and does not create repository commits. The Cloudflare API token is not needed here and should never be pasted into the website or repository.
