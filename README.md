# Dr. Amar Banerjee | Professional Website

Responsive executive portfolio website for Dr. Amar Banerjee, focused on technology strategy, AI innovation, data governance, digital engineering, research leadership and responsible AI.

## Features

- Executive profile and measurable business impact
- Career timeline across Tata Sons, Philips Healthcare, Siemens Research and Tata Research Development and Design Center
- Capability areas, selected publications and patents
- Leadership, teaching and professional service
- Responsive desktop and mobile experience
- Light and dark themes
- Accessible navigation and reduced-motion support
- SEO metadata, structured data, sitemap and robots file
- Static GitHub Pages deployment with no build dependencies

## Local preview

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Deployment

The repository is configured as a GitHub Pages user site. Publish from the `main` branch and repository root in GitHub Pages settings.
