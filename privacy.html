Privacy and analytics

Useful analytics without trying to identify you.

This website uses optional first-party anonymous analytics to understand which pages, research topics, programs and resources are useful. The design deliberately avoids storing raw IP addresses or attempting to discover a visitor's Google identity.

What may be recorded

When anonymous analytics is allowed, the site may record the page visited, sections reached, brochure downloads, contact-button clicks, referring website, coarse device/browser/operating-system family, language, and an approximate country, region and city supplied by the analytics infrastructure.

What is deliberately not stored

Raw IP addresses are not stored. The collector uses network metadata only to derive approximate geography. It does not request GPS location, does not attempt browser fingerprinting, and does not read or infer a Google account, email address or other third-party login identity.

Anonymous visitor recognition

If you allow analytics, the browser creates a random first-party identifier so the site can distinguish a new anonymous visitor from a returning anonymous visitor. The server immediately converts that random identifier into a salted one-way hash before storage. It is used for aggregate website understanding, not to identify a person.

Your choice

You can allow or decline anonymous analytics. Declining removes the local anonymous visitor/session identifiers used by this site. You can change the choice here at any time.

Storage and access

Detailed event data is intended to remain in the private analytics database. Only privacy-safe aggregate summaries may be published in the public website repository. Protected exports require an administrator token.
